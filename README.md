# BSU 422

Course materials for Bridgewater State University's [PHYS 422 - Computer Simulation in Physical Science](https://catalog.bridgew.edu/preview_program.php?catoid=15&poid=5477#)

As of 2023 this course is entitled "Computer Simulation in Physical Science", but is being written and taught more in the mind-set of "Numerical Methods in Physical Science". 

The course is python-based. 

## Setup
Information on setting up your computer in preparation for the courae can be found in [getting_setup.pdf](getting_setup.pdf) 

## Topics

The main topics covered in the course are:
1. [Python Fundamentals](A_fundamentals/)
2. [Data Analysis](B_data_analysis/)
3. [ODEs and Numerical Integration](C_NumericalMethods/)

Further details on the content within each topic can be found in the README.md file in the respective topic directories/folders.

## Projects 

As part of the course evaluation, students will perform small projects as the course progresses. 
This will include
1. Creating a simple package to download and plot data 
2. Using the pandas package to perform detailed analysis of a large scientific dataset.
3. Using numerical integration to simulate and then animate a physical system of interest. This could include:
   - Planetary Orbits 
   - Chaotic Systems 
   - Chemical Reactions
   - ...
