# Projects 

As part of the course evaluation, students will perform small projects as the course progresses.
This will include

A. Creating a simple package to download and plot data
 - See [Project_package_creation.ipynb](Project_package_creation.ipynb) for detailed specification of the Project.

B. Using the pandas package to perform detailed analysis of a large scientific dataset.

C. Using numerical integration to simulate and then animate a physical system of interest. This could include:
 - Planetary Orbits
 - Chaotic Systems
   - See the INCOMPLETE notebook, [Project_LorenzAttractor_INCOMPLETE.ipynb](Project_LorenzAttractor_INCOMPLETE.ipynb)
   - See the animation, lorenz_attractor.mp4 
 - Chemical Reactions
   - See the INCOMPLETE notebook, [Belousov-Zhabotinsky_INCOMPLETE.ipynb](Belousov-Zhabotinsky_INCOMPLETE.ipynb)
   - See the animations, [bz.mp4](bz.mp4) and [bz_c.mp4](bz_c.mp4) 
 - ...
